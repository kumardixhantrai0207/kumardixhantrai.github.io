# Kumar Dixhant Rai — Professional Portfolio

A premium, interactive, and fully responsive single-page portfolio website showcasing experience in **Research Administration, Operations Management, and Data & AI Engineering**.

Live Link: [kumardixhantrai0207.github.io/kumardixhantrai.github.io](https://kumardixhantrai0207.github.io/kumardixhantrai.github.io/)

---

## 🚀 Key Features

### 1. Light & Dark Themes
* Integrated a smooth theme-toggle switcher in the header.
* Persistent memory using `localStorage` to save user selection across sessions.
* Synchronized interactive particle canvas background (particles dynamically adjust opacity and contrast according to the selected theme).

### 2. Custom Inline SVG Illustrations
Each project features a custom split-pane layout containing interactive diagrams built entirely in responsive, theme-aware SVGs:
* **MASt Project**: Animated learning hierarchy tree showing adaptive competency pathways.
* **Pneumonia Detection**: Machine learning X-ray diagnostic scan animation with an active grid tracker.
* **Grant Budget Dashboard**: Data chart showing cost curves, budget caps, and predictive forecast path grids.

### 3. Widescreen Visual Continuity
* **CSS Grid Pattern Background**: A clean coordinate grid overlay running across the pages.
* **Vertical Scroll Tracker**: A left-hand margin progress tracker that highlights sections and fills dynamically from top to bottom as you scroll.
* **3D Tilt Cards**: Interactive 3D mouse hover tilt effects on project cards and pillars.
* **Custom Cursor**: Smooth lerp-follow cursor with hollow glowing ring expansions on hovers.

### 4. Detailed Experience & Coursework tags
* Coursework records formatted into responsive tag grids with hover highlights.
* Comprehensive outline of grant planning operations (reconciling a $2.2M sponsored research portfolio across 7 NSF & NIH awards).

## 🛠️ Technology Stack

* **Core**: Semantic HTML5, Vanilla CSS3 (Custom Variables, Flexbox, CSS Grid), Vanilla JavaScript (ES6+).
* **Animations**: CSS `@keyframes`, IntersectionObserver API, standard mouse listener matrix translations for 3D card rotations.
* **Graphics**: Inline responsive SVG vector paths.
